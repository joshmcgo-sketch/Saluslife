# Product photos

Drop a real product photo in **this folder**, named exactly `<product-id>.jpg`
(`.png`, `.webp`, and `.avif` also work). It is picked up automatically — no code
changes needed. Anything without a photo falls back to the line-art placeholder.

Then rebuild (`npm run build`) or, if the dev server is running, it hot-reloads.

Recommended: square-ish images, ~1000×1000px, on a plain/dark background so they
sit well on the dark cards.
